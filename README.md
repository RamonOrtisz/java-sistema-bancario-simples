# Sistema Bancário Simples em JAVA
Um sistema bancário simples desenvolvido em Java, com  interação pelo terminal, permitindo realizar operações básicas de 
uma conta bancária, como consultar saldo, depositar e sacar dinheiro.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da linguagem Java, especialmente estruturas 
de repetição, condicionais, métodos e manipulação de dados.

## 🚀Funcionalidades

Consultar saldo: visualizar o saldo atual da conta. <br>
Depositar: adicionar dinheiro ao saldo bancário. <br>
Sacar: retirar dinheiro, respeitando o limite disponível. <br>
Encerrar sistema: finalizar a execução do programa. <br>

## 📚 Conceitos praticados

Variáveis e tipos primitivos (double, boolean e int). <br>
Estruturas condicionais (if, else e switch). <br>
Estrutura de repetição (while). <br>
Métodos com e sem retorno (void e double). <br>
Passagem de parâmetros e retorno de valores. <br>
Entrada e saída de dados com Scanner. <br>
Validação básica de informações. <br>

## 🎯 Objetivo do projeto

Este projeto faz parte da minha jornada de aprendizado em Java, com foco na construção de uma base sólida em lógica de programação e organização de código.

A ideia é evoluir o sistema gradualmente, implementando novas funcionalidades e aplicando conceitos mais avançados da linguagem.
